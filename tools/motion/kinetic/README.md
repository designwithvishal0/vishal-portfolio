# Kinetic motion pieces (K1 four questions, K2 numerals)

Rebuild everything: `bash tools/motion/kinetic/render-all.sh` (about 5 minutes; set FRAMES to choose the frame folder, CRF to retune the question films, ENCODE_ONLY=1 to re-encode existing frames). Output goes to `public/kinetic/motion/`.

* `questions.html` + `questions.js` (K1): DOM type in Bricolage Grotesque Variable, every glyph a span set from a seeded hash every 3 frames, so the film is a pure function of (t, frame). 8 s, wide 1920x600 and tall 1080x600. Timeline: settled list 0.0 to 1.6, loosens into a staggered nervous layout 1.6 to 2.2 (glyph offsets 4 px or less, 2.5 degrees, weight 420 to 760, width 78 to 95%, opacity 85% or more, so every word stays legible), snaps back in work order 3.6 to 5.4 (damped spring, motion blur), holds to 8.0, which equals frame 0. The page plays it once per visit.
* `hero-cut.sh`: the Kinetic hero reels (`public/kinetic/reel/hero-wide.mp4`, `hero-tall.mp4` and posters), cut from the same showreel sources as `public/reel/cut.sh` but with no title cards or text columns, so frame 0 is product UI.
* `numerals.html` + `numerals.js` (K2): '60%', '50%', '30%' drawn at 2x on a canvas (800, width 75%), turned into signed distance fields; each digit change interpolates the fields top first, mixes in a blurred field for the melt, softens the edge and spreads the ink, then snaps crisp with a small negative spread overshoot. '0%' never changes.
* `render.cjs` renders frames or stills with Playwright (`node render.cjs questions wide light <dir> 2.5,9`); snap frames in K1 average 8 sub frames over a 180 degree shutter for motion blur. `render-all.sh` encodes H.264 (bt709, faststart), keeps VP9 only when smaller, writes posters (K1 at 0.0 s, the settled list) and the 60 K2 scrub frames as 900x900 WebP q72.
